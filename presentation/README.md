# ScholarCrew walkthrough deck

A 39-slide product walkthrough: the problem, how the AI crew works, every workflow with a live screenshot, the safety and privacy guardrails, pricing, and how the product was verified. Every slide has speaker notes.

| File | What it is |
|---|---|
| `ScholarCrew.html` | Web version. Open it in a browser. Arrow keys or space move between slides, `N` shows speaker notes, `F` goes full screen, and `#/n` links to a slide. Print to PDF from the browser for a handout. |
| `ScholarCrew.pptx` | PowerPoint version with editable text, real slide titles, sections, and speaker notes. Keynote opens it too. |
| `assets/` | The screenshots, captured from the running app with the fictional seed data (`pnpm db:seed`). |

All people, schools, scholarships, amounts, and prices in the screenshots are fictional sample data. ScholarCrew is a working name.
